# MUSE_HANDOFF — Museによる投稿の受け渡し

Instagramへの投稿は **Muse** が行います。このシステムは、承認済みの動画を Drive の受け渡しフォルダに置くところまでを担当します。

## Museに監視させるフォルダ

`instagram_post_reel/11_Muse投稿キュー` **だけ** を監視対象にしてください。

- ⚠️ `06_承認待ち` は監視させないでください。未承認の動画が入っています。
- `11_Muse投稿キュー` に入るのは、あなたが `/approve` した版だけです。承認時と同じファイル（sha256で照合）であることも確認してから置きます。

## キューに置かれるファイル（投稿1本につき3つ）

| ファイル | 内容 |
|---|---|
| `IG-YYYYMMDD-NNN.mp4` | 動画（9:16, 1080×1920, H.264/AAC） |
| `IG-YYYYMMDD-NNN.txt` | キャプション＋ハッシュタグ（そのまま投稿文に使える形） |
| `IG-YYYYMMDD-NNN.jpg` | カバー画像（サムネイル） |

ファイル名や形式をMuseの仕様に合わせる必要があれば、`config/publishing.json` を変更します。

## 流れ

1. 承認依頼（GitHub Issue）に `/approve` と返信する
2. 自動で `11_Muse投稿キュー` に上の3ファイルがコピーされ、Issueに通知が届く
3. Museが投稿する
4. 投稿できたら、Issueに `/posted https://www.instagram.com/reel/xxxx/` と返信する
5. 自動で次の処理が行われる
   - 投稿済みとして記録（URL・日時）
   - キューの3ファイルを `07_投稿済み/IG-…/` に移動（**Museが同じ動画を二度投稿しないため**）
   - Issueを閉じる

## 二重投稿・誤投稿の防止

| リスク | 対策 |
|---|---|
| 未承認の動画をMuseが投稿 | 未承認の動画はキューに入らない（状態とsha256を確認してからコピー） |
| `/approve` の二重送信 | 2回目は無視（状態チェック）。同名ファイルがあればコピーしない |
| 投稿後もファイルが残りMuseが再投稿 | `/posted` でキューから移動。**Museに「投稿したファイルは再投稿しない」設定があれば併用を推奨** |
| 承認後の差し替え | 承認時のsha256と一致しなければキューに置かない |

## 制約
- 投稿完了は `/posted` で手動記録します。Museから投稿URLを自動で受け取れるか確認でき次第、自動化を検討します。
- インサイトの自動取得はInstagram APIの接続が必要です（現在は未接続）。それまでは手動入力またはMuseの分析機能で補います。
- 将来Instagram APIで直接投稿したい場合は、`config/publishing.json` の `mode` を `api` に変えると、実装済みのAPI投稿に切り替わります。

## Museに渡すプロンプト（常時の指示）

Museに最初に一度渡して、常時の指示として使ってもらいます。変更したらこのファイルを更新してください。

```
あなたは、私のInstagramアカウントにリール動画を投稿する担当です。
次のルールを必ず守ってください。

■ 投稿する素材の場所
- Googleドライブの「instagram_post_reel」フォルダ内にある
  「11_Muse投稿キュー」フォルダだけを確認してください。
- 他のフォルダ（特に「06_承認待ち」）のファイルは、絶対に投稿しないでください。
  未承認の動画が入っています。

■ 1本分の素材
同じ投稿IDのファイルが3つで1セットです（投稿IDは IG-20261028-001 のような形式）。
- IG-xxxxxxxx-xxx.mp4 … リール動画（縦型9:16）
- IG-xxxxxxxx-xxx.txt … キャプション（ハッシュタグ込み）
- IG-xxxxxxxx-xxx.jpg … カバー画像
3つそろっていないものは投稿しないでください。

■ 投稿のしかた
- 種類は「リール」で投稿してください。
- キャプションは .txt の内容を一字一句そのまま使ってください。
  要約・言い換え・ハッシュタグの追加や削除はしないでください。
  末尾のクレジット表記（ナレーション音声・地図）も必ず残してください。
- カバー画像は .jpg を使ってください。
- 動画の編集・トリミング・BGMやエフェクトの追加はしないでください。
- 1回の確認で投稿するのは最大1本までにしてください。

■ 二重投稿の防止
- 同じ投稿IDは1回だけ投稿してください。
- 投稿前に、同じ投稿IDをすでに投稿していないか確認してください。
  自分が投稿したIDの記録と、アカウントの最近の投稿（同じキャプションがないか）の両方を見てください。
- 投稿が成功したか分からないときは再投稿せず、私に確認してください。
- 「11_Muse投稿キュー」のファイルを削除・移動・名前変更・編集しないでください。
  投稿後の片付けは別の仕組みが自動で行います。

■ 投稿後の報告
投稿できたら、次の形式で私に知らせてください。
  投稿完了: IG-xxxxxxxx-xxx
  URL: https://www.instagram.com/reel/xxxxxxxx/
  投稿日時: YYYY-MM-DD HH:MM

失敗した場合は、投稿IDとエラー内容を知らせてください。自動で何度もやり直さないでください。

■ （できる場合）投稿後の数値
投稿から24時間後・72時間後・7日後に、次の数値を投稿IDつきで知らせてください。
再生数、リーチ、いいね、コメント、保存、シェア、平均視聴時間。
取得できない数値は「取得不可」と書き、推測で埋めないでください。
```

Museから「投稿完了」の報告が来たら、GitHubの承認Issueに `/posted <URL>` と返信します。
