# BRAND_GUIDELINES — 見た目のルール

設定ファイル: `config/brand.json`（コードはこの値を使って描画します）

## 色（2026-11-01 改定）
| 役割 | 値 | 使い方 |
|---|---|---|
| メイン（ベージュ） | `#F7F3E9` | 背景。紙のような質感＋うっすらグリーンの方眼 |
| サブ（ディープグリーン） | `#2F855A` | 変化・エネルギー・徳島のハイライト、棒グラフ、渦潮、地図の輪郭、字幕枠 |
| アクセント（テラコッタ） | `#C53030` | フック、驚き、重要な数字（見出しの強調語、カウンター、ピン、エネルギーの線） |
| 文字（インク） | `#24302A` | 見出し・字幕・ラベルの本文（ベージュ上のコントラスト 12.4:1） |
| 補助 | パネル `#FFFDF7` / 地図の陸 `#EBE2CE` / 補足文字 `#6F6858` | 字幕の帯、注記 |

- テラコッタ（4.9:1）とディープグリーン（4.1:1）は大きな文字・数字・図形に使い、小さな本文はインクで書く。
- アクセントは1画面に1〜2要素まで。
- 徳島が登場する場面は、ディープグリーンの発光＋テラコッタのピン/エネルギー線＋ズームで「主役感」を出す。
- 色はコードに直接書かず、`config/brand.json` の役割名（bg / ink / sub / accent など）で指定する。

## 画面
- 縦型 9:16、1080×1920、30fps、H.264 / AAC 48kHz、音量 -14 LUFS。
- 安全領域（InstagramのUIと重ならない範囲）: 上 220px・下 420px・左 72px・右 168px を避ける。
- 構成: 上部（y 300前後）に見出し → 中央（y 450〜1180）にビジュアル → 字幕帯（中心 y 1330）。

## 文字
| 用途 | フォント | サイズ |
|---|---|---|
| 見出し・数字 | Dela Gothic One | 70〜110px |
| 字幕 | Dela Gothic One（黒縁3px＋半透明の黒帯） | 64px、1行最大13文字、最大2〜3行 |
| 注記・ラベル | Noto Sans JP（太さ600〜900） | 34〜50px |

- 字幕はナレーションの1文ごとに切り替え、改行は句読点か台本の `|` の位置だけ（単語の途中で改行しない）。
- 字幕内の数字・キーワードは台本の `emphasis` で黄色にする。

## アニメーション
- イージング: 登場は ease-out / ease-out-back（軽く弾む）、移動とズームは ease-in-out。
- 見出しは行ごとに0.18秒ずらしてポップイン。シーン切替は0.22秒のクロスフェード＋効果音（whoosh）。
- 大きな変化（月の接近・渦の加速）には小さな画面揺れを入れる。
- 地図のズームは対数スケールで、全体→目的地へ一気に寄る。
- 1シーンの長さはナレーションから自動決定（最短 `min_duration`）。

## 音
- BGM: コード生成のシネマティックなループ（Am-F-C-G）。徳島が登場するシーンに向けて盛り上がる。
- ナレーション中はBGMを自動で下げる（ダッキング）。
- 効果音: whoosh（場面転換）、impact（徳島の登場）、riser（溜め）、ding（数値の決定）、tick（カウンター）。

## シリーズ表記
- 画面上にシリーズ名は表示しない（2026-11-01 変更。`config/brand.json` の `show_series_label: false`）。
- 最後の画面に次回予告の文言は入れない。問いかけ（例: あなたなら見に行く？）で締める。

## ナレーション

- 読み間違えやすい語は台本の `tts` をひらがなで書く（例: 月 → つき）。
