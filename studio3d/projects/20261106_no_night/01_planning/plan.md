# 企画：もしも地球から「夜」がなくなったら？

- アカウント：世界の仕様外　形式：「もしも〇〇がなくなったら？」＋早送り時計（夜が消えてから ▶▶×N）
- 尺：50秒（5秒×10シーン）　画質：hd（720×1280で描画 → 1080×1920）　音：BGM＋画面の文字（ナレーションなし）
- 見た目：ブロック調のジオラマ（箱を組んだ人・動物・街）。柔らかい影と光で質感を出す
- 展開：日常（眠れない）→ 夜空 → 生き物（子ガメ・ホタル・夜行性の動物）→ 社会（時計・花火）→ 徳島オチ
- オチ：世界中が困る中、徳島だけは昼でも阿波踊りを踊っている（地域を持ち上げる明るいオチ。最初は徳島を出さない）
- 参考：オーナー提供の参考動画（ブロック調3D＋早送り時計の構成）。テーマ・文章・レイアウトはそのまま使わず、オリジナルで作る
