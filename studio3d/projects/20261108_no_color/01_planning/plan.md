# 企画：もしも地球から「色」がなくなったら？

- アカウント：世界の仕様外　形式：「もしも〇〇がなくなったら？」＋早送り時計（前回「夜」と同じシリーズ）
- 尺：50秒（5秒×10シーン）　画質：hd　音：ナレーション（音読さん Masaru・ですます調）＋効果音＋BGM（コード生成）
- 選定理由：最初の1秒で「色が抜ける」変化が無音でも一目でわかる。身近（信号・ごはん・運動会・虹）。前回の人物・街・祭りセットを再利用でき当日中に完成できる。企画表 ideas/2026-11-08.json で総合1位（93.0）。
- 展開：色が抜ける → 信号 → 食卓 → 運動会 → 花とハチ → 虹 → 世界中が灰色 → 徳島の藍だけ残る → 藍色の阿波おどり
- 色抜きは仕上げの画像処理（studio3d/grade.py）。藍（暗く鮮やかな青）だけ色を残す。明るい空の青は残らない。
