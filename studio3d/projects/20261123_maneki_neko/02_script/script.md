# 台本：もしも商店街に巨大な招き猫が現れたら？（30秒・ナレーション／字幕なし）

| # | 秒 | 内容 | 音 |
|---|---|---|---|
| s01 | 0–5 | 昼の商店街。人々が歩く。揺れ → 奥の屋根の向こうから高さ30mの招き猫がせり上がる | ざわめき・鳥 → 地鳴り・重低音・足音 |
| s02 | 5–11 | 招き猫が右手を大きく振る。風でのぼりがはためき商品が飛ぶ。一歩で自販機が倒れる | 風・風切り・足音・衝撃 |
| s03 | 11–18 | 人々が逃げる。手の振り下ろし、紙吹雪と落ち葉が舞う（スロー）。招き猫が突然止まる | ざわめき・衝撃・風 |
| s04 | 18–22 | 遠くからお囃子。カメラが反対側へパン。浴衣と編笠の踊り手の列が踊りながら進んでくる | お囃子が近づく |
| s05 | 22–27 | 踊り手が招き猫を囲む。先頭の踊り手の前で、招き猫が首をかしげ、片足を上げて踊り始める | お囃子が主役に |
| s06 | 27–30 | 数百人の踊り手と招き猫が一斉に踊る。満面の笑み、両手を上げた決めポーズ | 最高潮で終了 |
