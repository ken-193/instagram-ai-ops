## 主張と区分（台本で使う数字）
| 主張 | 区分 | 根拠・計算 |
|---|---|---|
| 竜宮で3年、地上で300年 | verified（話による） | 風土記系の話の年数［S1］。明治の国定教科書版は700年後［S2］。キャプションに「お話によって違う」と書く |
| 太郎の3年＝移動中 | assumption | 時間の遅れは移動中に起きるため、3年がまるごと移動中と仮定 |
| 光速の99.995% | estimate | 時間が100倍遅れる速さ：v = c√(1−1/100²) ≈ 0.99995c |
| 亀の普段の速さ 時速約1.5km | verified＋assumption | アカウミガメの巡航速度 秒速0.28〜0.51m（時速約1.0〜1.8km）［S3］の中間 |
| いつもの7億倍 | estimate | 光速 時速約10.8億km ÷ 1.5km/h ≈ 7.2億 |
| 竜宮城は片道150光年先 | estimate | 地上の300年が往復の移動時間、ほぼ光速なので片道150光年 |
| 約3,000万G | estimate | 1秒で秒速30万kmまで加速：3.0×10⁸ m/s² ÷ 9.8 ≈ 3,060万G |
| 人類のエネルギー12年分 | assumption＋estimate | 太郎＋亀＝200kgと仮定。(γ−1)mc² = 99×200×(3×10⁸)² ≈ 1.8×10²¹J ÷ 世界の年間エネルギー消費 592EJ［S4］≈ 3年分。加速・減速4回で12年分 |
| 海が割れる・ちりが放射線の弾丸に | fiction（理屈は実在） | 超高速の衝突エネルギーを誇張して映像化 |
| 玉手箱の煙＝300年分の時間 | fiction | 締めの解釈 |
