# 企画：もしも人間が全員1cmになったら？

- アカウント：世界の仕様外　形式：「もしも〇〇になったら？」＋早送り時計（「夜」「色」と同じシリーズ）
- 尺：50秒（5秒×10シーン）　画質：hd　音：ナレーション（音読さん Masaru・ですます調）＋効果音＋BGM（s09〜s10 は祭り囃子）
- 選定理由：ideas/2026-11-23.json で総合1位（89.0）。オーナーが選択。最初の1秒で「人が縮む」変化が無音でも分かる。大きさの比較は競合リサーチ（MetaBallStudios など）でも反応が大きい型。
- 作り方：人を普通の大きさのまま置き、身の回りの物を170倍で作る（身長170cmの人が1cmになると、世界は約170倍に見える）。
- 展開：縮む → コップ → ネコ → 雨粒 → スマホ → たたみ → 世界 → 徳島の家ほどのすだち → すだちを運ぶ → すだちのまわりで阿波おどり
